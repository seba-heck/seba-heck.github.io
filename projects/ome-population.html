Abstract

In the scientific fields Partial Differential Equations (PDE) are used to describe the world. Traditional methods for deriving PDEs were using conservation laws, physical principles and other phenomenological behaviors. Since discovering these equations is such an important part of science new data-driven methos were developed. This is a long standing topic and various methods were explored, but outstanding are Symbolic Regression and Evolutionary algorithms. These methods use spatio-temporal data and regression frameworks to find the fitting equation. Specific methods for PDEs were developed with sparse regression. But this method is computational expensive and is therefore limited to smaller function space. To increase the capabilities, new optimization method are proposed namely population-based optimization methods. These methods can be very effective and should have a smaller footprint. The current state-of-the-art methods often use graph representations for the functions and modify it with genetic algorithms. With this approach it is possible to explore an almost unlimited space of equations.
